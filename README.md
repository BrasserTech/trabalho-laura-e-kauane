# AcadUp

Protótipo de atividades complementares em React e TypeScript, com Vite e Node.js.

## Executar

Abra o terminal na pasta principal do projeto.

```sh
npm install
npm run dev
```

Abra o endereço Local exibido pelo Vite. Para verificar os tipos e gerar a versão de produção, use `npm run build`.

Em desenvolvimento, o formulário é preenchido com `aluno@acadup.test` e `acadup123`. A sessão começa com 120 horas e favoritos de exemplo. Os botões Google e Apple simulam o acesso. O login é demonstrativo. Use qualquer e-mail válido e uma senha de teste com pelo menos quatro caracteres. O perfil, os favoritos e as inscrições ficam no `sessionStorage` da aba e sobrevivem a recarregamentos. A senha não é guardada. Para somar horas, inscreva-se em um curso e marque-o como concluído.
